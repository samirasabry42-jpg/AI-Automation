HOW IT WORKS

Five workflows.
One connected system.

Public actions run the relevant workflows. Screening and monitoring work in the background.

01 · FORM / WEBHOOK

Application intake

Validate the submission, check duplicates, save the CV in Drive and record an application in Sheets.

02 · SCHEDULE

AI screening

Read pending applications, extract CV information and record an AI assessment for recruitment review.

03 · ERROR + SCHEDULE

Error monitoring

Log workflow failures, manage alerts and check whether the application queue is moving.

04 · CHAT / WEBHOOK

Policy assistant

Search the HR knowledge base and answer with policy context and sources.

05 · FORM / WEBHOOK

Career coaching

Compare a CV with a role, prepare application materials and return a coaching report.
